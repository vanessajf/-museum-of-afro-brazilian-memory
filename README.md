# Museu Digital Afro-Brasileiro

Site sobre história e cultura afro-brasileira, criado com Bootstrap 5.

## Funcionalidades

- Navbar responsiva
- Galeria de temas (Capoeira, Samba, Religiões, Memória)
- Seção sobre preservação digital
- Informações sobre a Lei 10.639/2003
- Layout responsivo

## Como rodar

Abra o arquivo `index.html` no navegador.

## Referências

- Artigo: *The Dilemmas of Digital Patrimonialization* — Livio Sansone (2013)
- Site original: [Museu Afro-Digital UFBA](https://museuafrodigital.ufba.br/)
